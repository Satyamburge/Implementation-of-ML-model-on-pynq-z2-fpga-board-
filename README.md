# Implementation of Machine Learning Models on PYNQ-Z2 FPGA Board

## 📌 Project Overview
This project implements machine learning models on the PYNQ-Z2 FPGA board
to predict temperature values using collected sensor data.

The project explores Linear Regression and Logarithmic Regression
for temperature prediction and data analysis.

## 🎯 Objectives
- Collect temperature sensor data.
- Implement Linear Regression.
- Implement Logarithmic Regression.
- Analyze predicted and actual temperature values.
- Explore machine learning applications on FPGA platforms.

## 🛠️ Hardware and Software
- Hardware: PYNQ-Z2 FPGA Board
- Programming Language: Python
- Libraries: NumPy, Matplotlib
- Environment: Jupyter Notebook / PYNQ

## 📂 Project Files
- `linear_regression.py` – Linear regression model.
- `logarithmicRegression.py` – Logarithmic regression model.
- `plottingresults.py` – Visualization of results.
- `collection of 300 samples` – Temperature sample collection script or data.
- `architecture of pynq.png` – System architecture.
- `block diagram.png` – Project block diagram.

## ⚙️ Methodology
1. Collect temperature samples.
2. Process the collected data.
3. Train regression models.
4. Predict temperature values.
5. Visualize and analyze the results.
